## 🛠️ What the Tool Does
 
The tool takes **Markdown**, a plain-text format that uses simple symbols for formatting, and produces a **PDF**, a fixed-layout document that looks the same everywhere.
 
| You provide | You get |
|-------------|---------|
| `# Title` | A large heading |
| `**bold**` and `*italic*` | Bold and italic text |
| `- item` | A bulleted list |
| `\| a \| b \|` tables | A formatted table |
| Fenced code blocks | A code block in the document |
| `[text](url)` | A clickable link |
 
You see the result in a live preview first, so there are no surprises when you export.

## 📘 Usage Guide
 
### Method 1: Paste your Markdown
 
1. Open the [Markdown to PDF tool](https://markdownonlineviewer.com/markdown-to-pdf).
2. Copy your Markdown from your editor, notes app, or chat.
3. Paste it into the editor panel.
4. Review the preview.
5. Export the PDF.
### Method 2: Upload a `.md` file
 
1. Open the tool.
2. Click **Upload .md file**.
3. Choose the file from your device.
4. Review the preview.
5. Export the PDF.
### Method 3: Start from other content
 
If your content is in Word, Google Docs, or a web page, first convert it with the **Rich text to Markdown** or **Paste to Markdown** tool on [markdownonlineviewer.com](https://markdownonlineviewer.com/), then export it as a PDF.
 
### Before you export: a quick checklist
 
- [ ] Headings are in a logical order
- [ ] Lists and tables look right in the preview
- [ ] Images appear (use full URLs)
- [ ] Links point to the right pages
- [ ] Code blocks are formatted correctly
